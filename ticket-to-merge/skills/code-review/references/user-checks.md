## Things to think about

Ideas to help you decide what belongs here. None of them is active.

- Logging: what must be logged, and what must never be logged.
- Error messages: wording, whether they may expose internals.
- Performance: queries without limits, work done inside loops.
- Accessibility or markup rules for the views.
- Naming rules for routes, services, repository functions.
- Anything the team has been burned by before.
